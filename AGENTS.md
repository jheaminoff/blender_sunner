# Sunner engineering notes

- Blender 5.2.x extension, tested on 5.2.3 LTS. Source is `sunner/`; current package is `dist/sunner-0.4.0.zip`. No third-party runtime dependencies.
- Git repository, public at `github.com/jheaminoff/blender_sunner` (`main`). `3dTampereBlender` imports this checkout through `sys.path`, so uncommitted edits here go live in its renders; develop in `~/Developer/_worktrees/blender_sunner--<topic>` and merge when verified.
- `rig.create(scene)`, `rig.parts(scene)`, `rig.remove(scene)` and `rig.configure_twilight(scene, sky_gain, moon_gain)` are consumed by the separate `~/Developer/3dTampereBlender` project. Preserve this API when changing internals. Other projects must not edit this checkout concurrently.
- The authoritative cycle is the day dial's unbounded local X rotation. Heading and path tilt are its parent's Z/Y rotations; season (declination) drives the sun/moon objects' local Y rotation. Every elevation/azimuth driver reads the sun object's evaluated `matrix_world[2]` (its +Z axis), so there is one direction source. Do not add a second synchronized time state or per-frame callbacks.
- In World shaders `Texture Coordinate > Generated` is the view direction and `Normal` is its negation. The 0.1 night gradient is calibrated on `Normal`; stars and discs use `Generated`.
- Rigs older than the current version are changed only by `rig.update(scene)` / **Update cycle**, which adds `OPTIONAL_CONTROLS` without overwriting saved values and rebuilds the managed World nodes. The World is an allowed user of both light data-blocks because disc drivers read their energy/temperature.
- Native simple driver expressions and shader nodes must evaluate after reopening with the extension and Python auto-run disabled. Blender truncates driver expressions at 255 UTF-8 bytes; `lighting.drive()` rejects longer strings before assignment. Twilight formulas use short variable aliases and degree thresholds to stay within that limit.
- Blender Sky Texture azimuth is measured clockwise from +Y: use `atan2(direction.x, direction.y)`. `MULTIPLE_SCATTERING` and `aerosol_density` are the 5.2 API, not old `NISHITA`/`dust_density` examples.
- Only the managed World has sky sun-disc lighting disabled and `sun_threshold=0`. Explicit SUN light objects supply direct illumination. Never edit the original World or silently change exposure/render engine.
- Scene `sunner_rig` points to the owned collection. The collection retains the original World and separate object/light-data references, so cleanup still works if an object is deleted. External references block removal instead of breaking another scene.
- Run focused integration checks: `blender --background --factory-startup --python-exit-code 1 --python tests/test_cycle.py` and the same command with `tests/test_weather.py`. The weather suite includes saved-file/no-extension evaluation and compatibility with a rig constructed from the retained 0.1 ZIP.
- Optional weather is a separately owned child collection; `sunner.weather.create/parts/preset/bind_camera/remove` does not change core light gains or existing rigs automatically. Its root stores weather controls; lengths are metres converted using scene unit scale. Removal validates the collection schema and preserves external cameras and user materials.
- Small shader values can be quantized to zero when assigned through native drivers. Fog receives driven visibility distance and unit scale, then performs division in shader math; cloud coordinates use the same approach. Keep native camera-target fallback drivers so deleting a rain camera disables the effect without a Python handler.
- `tests/render_weather.py` produces bounded serial Cycles/EEVEE samples, timings and `examples/sunner-weather.blend`; `tests/contact_sheet.py --weather` builds its contact sheet. EEVEE volume shadows are an explicit scene/test choice, not an automatic weather side effect. Coordinate heavy renders with the 3dTampereBlender session while its city conversion batches run.
- UI smoke is a separate disposable foreground window: `blender --factory-startup --enable-event-simulate --python-exit-code 1 --python tests/test_ui.py`. Also inspect `examples/ui-smoke.json` and the actual panel screenshots; timer failures are recorded there. The test dismisses each popup before opening the next branch: changing properties alone can leave a stale popup in an otherwise successful screenshot.
- Build: `mkdir -p dist && (cd sunner && blender --command extension validate && blender --command extension build --output-dir ../dist)`. Validate the resulting ZIP and run `tests/test_install.py` with an isolated `BLENDER_USER_RESOURCES` directory. Never install test packages into the user's real profile.
- `tests/render_samples.py` generates Cycles/EEVEE comparisons and the example. It replaces PNGs only in its own `examples/renders/<engine>/` directory. Inspect the contact sheet before accepting lighting changes.
- `tests/contact_sheet.py` requires Pillow only for development. On this machine it works with `~/.pyenv/versions/3.12.8/bin/python3`; detached jobs may select a different Python, so use the explicit interpreter there.
- The Captain authorized installing Sunner in the normal local Blender profile and keeping that installation synchronized after verified Sunner updates. Rebuild and validate the ZIP, test it in an isolated profile, then update/enable the user's installed add-on while preserving preferences. Report when an already-running Blender needs a restart. This does not authorize Blender application upgrades or changes to saved scenes.
- Local updater: `blender --background --factory-startup --threads 1 --python-exit-code 1 --python tools/install_local.py -- --zip dist/sunner-0.4.0.zip`. It reads real preferences before saving; private backups/receipt stay in Blender's configuration directory. Test repeat installation and normal-profile startup in an isolated profile before changing installer behavior.
- `tests/render_sky.py` + `tests/sky_sheet.py` render the season/star/disc shots into `examples/sky/` and tile them using Blender only (no Pillow). Keep Cycles denoising off for star shots.
- UI smoke selects the real sidebar tab with `region.active_panel_category = "Sunner"`; open each popup/tab in its own timer tick after the previous ESC.
- The GitHub repository is public by the Captain's decision (2026-10-28). Uploading to the Blender Extensions platform still needs approval.
